# ADR-0011: Медиа: внешнее хранилище по умолчанию

- Статус: принято
- Дата: 2026-10-30

## Контекст

Загрузка файлов — классический путь к RCE.

## Решение

По умолчанию S3-совместимое хранилище — RCE через загрузку исключается как класс. Local-адаптер — Degraded Mode: вне webroot, постоянное предупреждение, сигнал AppSensor. Системные имена, проверка типа по содержимому, перекодирование изображений, SVG запрещён; MVP: jpg/png/webp/gif/pdf. Раздача локальных файлов: X-Sendfile или стриминг.

## Последствия

Установщик помогает подключить S3/R2/B2.
