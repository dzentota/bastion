# ADR-0014: Обновления и цепочка поставок (по модели Airship)

- Статус: принято
- Дата: 2026-10-30

## Контекст

Правило 11 манифеста.

## Решение

Только подписанные пакеты из собственного реестра, верификация через Chronicle; зависимости вендорятся; SBOM в релизе; автообновления безопасности по умолчанию; ключ подписи офлайн. Halite для секретов в БД.
