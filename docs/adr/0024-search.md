# ADR-0024: Полнотекстовый поиск

- Статус: принято
- Дата: 2026-10-31

## Контекст

Сайту документации нужен поиск (docs/roadmap.md, релиз 7) — без внешних служб, на shared-хостинге, на EN и RU.

## Решение

- **Интерфейс `SearchIndex`**, две реализации: SQLite FTS5 (`unicode61 remove_diacritics 2`, ранжирование bm25, заголовок весит в 5 раз больше) и MySQL/MariaDB FULLTEXT (InnoDB, BOOLEAN MODE, отрывок строится в PHP). Миграция 0006 создаёт индекс и заполняет его опубликованными записями.
- **Индексируется только опубликованное**, в момент публикации; каждый результат ещё раз сверяется со статусом в `entries`. Сохранённые, но не опубликованные изменения не ищутся. Индекс — на язык (`lang`), поиск идёт только в языке страницы.
- **Запрос не попадает в синтаксис движка:** разбивается на слова из букв и цифр (до 8, до 40 символов), каждое — фраза в кавычках; префиксный поиск — от 3 символов. Запрос до 200 байт, до 20 результатов.
- **Подсветка:** движок окружает совпадения символами частной области Unicode (U+E000/U+E001); отрывок экранируется, и только затем маркеры становятся `<mark>`.
- `/{язык}/search?q=…`, форма в шапке темы; `X-Robots-Tag: noindex`; запросы не журналируются.

## Последствия

- Без морфологии: русские словоформы находятся префиксом («установ» → «установка», «установить»), но не «шёл» → «идти».
- Встроенная модель угроз и страницы историй не индексируются (их данные — не записи CMS).
- Abuser Stories в `threat-model/search.php`: search-query-injection, search-dos, search-draft-leak, search-reflected-xss.
- Реализация MySQL не проверялась на настоящем сервере.
