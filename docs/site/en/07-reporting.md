# Reporting a vulnerability

Please do not open a public issue for a vulnerability. Use the private vulnerability reporting of the repository on GitHub (Security, then Report a vulnerability).

Tell us what you found, how to reproduce it and what an attacker could do with it. If the issue is in a library that Bastion uses, say which one.

Other problems, including mistakes in this documentation, can be reported as ordinary issues.
