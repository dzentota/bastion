# ADR-0012: Расширения: in-process, манифест прав, Gossamer

- Статус: принято
- Дата: 2026-10-30

## Контекст

Экосистема плагинов — главный источник уязвимостей WordPress; в PHP нет in-process песочницы.

## Решение

Расширение получает только Facades по манифесту; Static Gate при установке; подпись Publisher Key, проверка по Chronicle (модель Gossamer); отзыв ключей Super Provider. Расширение — отдельная зона доверия в модели угроз. Gears из Airship (подмена классов ядра) отклонены.

## Последствия

Это граница доверия на уровне политики, а не жёсткая изоляция — документируется честно.

## Уточнение: реализация (2026-10-30)

Поток установки — как в CMS Airship (подписанный пакет, проверка до записи, включение админом),
но без её слабостей, найденных в исходниках Airship:

| Airship | Bastion |
|---|---|
| Подпись проверяется только при установке; PHAR подключается с диска на каждом запросе без проверки | Хэш каждого файла сверяется с HMAC-подписанным реестром при **каждой** загрузке; исполняются проверенные байты (`eval` проверенного содержимого — без TOCTOU; цена: нет opcache для расширений) |
| Нет модели прав; Gears подменяют классы ядра | Манифест прав + фасады (`render.helper`, `content.read`); Static Gate по allowlist |
| `update_trigger.php` и shell-скрипты исполняются при установке | При установке не исполняется ничего |
| `bypassSecurityAndJustInstall` | Обхода проверок нет |
| Отката нет | Версии ставятся в отдельные каталоги атомарно (temp + rename); даунгрейд запрещён |

- Пакет: ZIP + отдельный `.sig` (Ed25519 над BLAKE2b-512 всего архива). Инструмент издателя — `bin/bastion-ext keygen|pack`.
- Источник в этой итерации — загрузка в админке. Удалённый канал и Chronicle — вместе с update-hijack.
- Доверие: ключ издателя закрепляется при первой установке (админ сверяет отпечаток); новые версии — только тем же ключом.
- Новая версия, которая просит новые права, ставится выключенной.
- Static Gate — граница политики, а не песочница: надёжна, пока исполняется только проверенный парсером код.
