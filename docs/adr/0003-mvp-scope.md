# ADR-0003: Объём MVP

- Статус: принято
- Дата: 2026-10-30

## Контекст

Нужно ограничить первую версию.

## Решение

Посты, страницы, рубрики, теги, медиа, пользователи с ролями Admin/Editor/Author, темы, расширения, анонимные комментарии с модерацией, AppSensor-панель. Без мультисайта и публичного REST API.

## Последствия

Комментарии — главная внешняя поверхность атаки и полигон для AppSensor.
