# Documentation

Bastion is a content management system built to show that security can be the main feature of a product rather than an afterthought. It runs on ordinary shared hosting: PHP 8.3 or newer and SQLite or MySQL, no daemons, no shell access required.

These pages are for two kinds of readers: operators who install and run a Bastion site, and security reviewers who want to check our claims against the threat model and the code.

## Where to start

- Installation: from an uploaded archive to a signed-in administrator.
- Hardening: what to check before the site goes public.
- Updates: how a new release is installed and how database migrations are applied.
- Backups: what to keep and how to restore it.

The security model, generated from the repository at release time, is in its own section.
