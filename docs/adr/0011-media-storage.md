# ADR-0011: Медиа: внешнее хранилище по умолчанию

- Статус: принято
- Дата: 2026-10-30

## Контекст

Загрузка файлов — классический путь к RCE.

## Решение

По умолчанию S3-совместимое хранилище — RCE через загрузку исключается как класс. Local-адаптер — Degraded Mode: вне webroot, постоянное предупреждение, сигнал AppSensor. Системные имена, проверка типа по содержимому, перекодирование изображений, SVG запрещён; MVP: jpg/png/webp/gif/pdf. Раздача локальных файлов: X-Sendfile или стриминг.

## Последствия

Установщик помогает подключить S3/R2/B2.

## Уточнение (реализация, 2026-10-30)

- Тип определяется по магическим байтам и должен совпасть с `finfo`; имя и Content-Type клиента игнорируются.
- Размеры изображения проверяются по заголовку до декодирования (≤ 12000 px по стороне, ≤ 40 Мп).
- Изображения перекодируются GD. Цена: анимированные GIF становятся статичными, ICC-профили теряются.
- PDF не перекодируется. Отклоняются PDF с JavaScript, действиями, вложениями, формами, шифрованием
  и **сжатыми объектными потоками** (`/ObjStm`) — их содержимое нельзя проверить без полного парсера.
  Цена: часть PDF, сохранённых современными редакторами, не загрузится. PDF всегда отдаётся как вложение.
- Раздача `/media/{id}`: `Content-Type` из `MediaKind`, `nosniff`, `CSP: default-src 'none'; sandbox`.
  ID — 128 бит случайности; медиа из черновиков доступны по прямой ссылке (не перечисляются).
- S3: path-style, SigV4, HTTP только через dzentota/http-client. `S3Config` дополнительно отвергает
  IP-литералы из приватных/зарезервированных диапазонов (см. docs/library-issues.md #19).
- Квоты: 200 файлов и 500 МБ на аккаунт в сутки, 10 МБ на файл; AppSensor FIO1/FIO2.
