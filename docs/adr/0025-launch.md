# ADR-0025: Запуск сайта документации

- Статус: принято
- Дата: 2026-10-31

## Контекст

Последний релиз дорожной карты (docs/roadmap.md, релиз 8): сайт документации Bastion работает на самом Bastion — на VPS, при желании за CDN; ADR публикуются из репозитория.

## Решение

- **Без cookie на публичных страницах.** Сессия и CSRF — только в `/admin` и `/install` (`StaffArea`). Раньше каждый посетитель получал cookie и строку в таблице сессий: за CDN это либо отключает кэш, либо — хуже — кэширует чужую сессию для всех. Публичная зона принимает только GET/HEAD и `POST /comments` (подписанный honeypot), остальное — 405. Публичные ответы — `Cache-Control: public, max-age=60, s-maxage=300`.
- **Адрес клиента за CDN** определяет веб-сервер (`real_ip` только для диапазонов CDN), не приложение: так AppSensor видит посетителя, а подделать адрес заголовком нельзя.
- **ADR из репозитория:** `bin/bastion docs:sync-adr [язык]` — `docs/adr/NNNN-*.md` → `/{язык}/adr-NNNN` под `/{язык}/adr`; переводы — `docs/adr/<язык>/`. Записи помечены источником (миграция 0007) и в CMS только для чтения; каждое изменение — подписанная ревизия, публикация, индекс, аудит. Страницу CMS на том же адресе синхронизация не трогает.
- **Стартовое содержимое:** `bin/bastion docs:import-site` — `docs/site/<язык>/NN-имя.md` с шапкой (`slug`, `parent`, `menu`). После импорта страницы принадлежат CMS и больше не перезаписываются. Встроенные виды модели угроз — строкой `::: threatmodel <вид>`.
- **Релиз:** `bin/release X.Y.Z` — гейт и тесты, экспорт модели угроз, чистое дерево из `git archive` (тесты и dev-конфигурация — export-ignore), vendor/ без dev-пакетов, SBOM внутри релиза с проверкой, воспроизводимый zip и SHA-256.
- **Сервер:** `deploy/nginx.conf`, `deploy/Caddyfile` (без CDN), `deploy/php-fpm-bastion.conf`; руководство — `docs/deploy.md`. `allow_url_fopen` остаётся включённым: http-client работает через stream wrappers.
- **Сообщения о проблемах:** `site.issues_url` (только https) — ссылка в подвале; об уязвимостях — закрытым сообщением на GitHub.

## Последствия

- После публикации CDN может показывать прежнюю версию до 5 минут.
- ADR пока только на русском; английский раздел появится, когда в `docs/adr/en/` будут переводы.
- Abuser Stories в `threat-model/launch.php`: cdn-session-sharing, managed-content-override.
- Что остаётся оператору: VPS, домен и DNS, сертификаты, CDN, перенос содержимого — см. docs/deploy.md.
