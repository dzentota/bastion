# ADR-0019: Мультиязычность контента и интерфейса

- Статус: принято
- Дата: 2026-10-31

## Контекст

Сайт документации Bastion — на EN и RU (docs/roadmap.md, релиз 2). Нужны переводы записей и интерфейса админки и темы.

## Решение

- **Контент.** Запись — один язык; переводы — отдельные записи с общей `translation_group` (миграция 0002). Свой slug (уникален в пределах языка) и свой статус: перевод может отставать, не блокируя публикацию. Язык фиксируется при создании; «Добавить перевод» создаёт черновик с блоками исходника.
- **Языки сайта** — `site.languages` и `site.default_language` в config.json, задаются в установщике. Без ключей — `en`. Существующие записи получают язык по умолчанию.
- **URL.** Все языки с префиксом: `/{lang}`, `/{lang}/{slug}`, `/{lang}/category|tag/{slug}`; `/` → язык по умолчанию. Старые `/{slug}`, `/category/…`, `/tag/…` отвечают 301. Дерево маршрутов держит один параметр на уровень, поэтому `/{lang}` и старый `/{slug}` — один обработчик. Язык из URL принимается только из списка языков сайта.
- **Тема** получает `lang`, hreflang и переключатель языков только по опубликованным вариантам. Рубрики и теги общие для языков; листинги фильтруются по языку. Меню — у каждого языка своё.
- **Интерфейс.** Каталоги `translations/{admin,theme,messages}/{lang}.json`, английский — исходный и запасной. В шаблонах `{{ t.key }}` (DSL без литералов — каталог передаётся контекстом); сообщения контроллеров переводятся по английскому тексту. JSON, а не PHP: подброшенный каталог не исполняется. Язык админки — у пользователя (миграция 0003), по умолчанию — язык сайта, если для него есть каталог.

## Последствия

- Abuser Stories в `threat-model/i18n.php`: translation-hijack, language-parameter-abuse, draft-translation-leak, legacy-redirect-abuse, catalog-injection, ui-locale-tampering.
- Не переведены динамические сообщения (тексты исключений, уведомления SecurityPosture с датами, описания capability расширений, действия журнала аудита).
- Перевод рубрик и тегов, выбор языка по Accept-Language и настройка языков из админки — позже (нужен экран настроек).
