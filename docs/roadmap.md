# Дорожная карта: от MVP к полноценной CMS

Дата: 2026-10-31

## Цель

Bastion вырастает из MVP в полноценную CMS. Критерий готовности — сайт документации и модели угроз Bastion, работающий на самом Bastion в проде, на EN и RU.

## Принципы

- Аудитория CMS — по-прежнему владельцы сайтов на shared-хостинге (ADR-0002). Аудитория документации — операторы и security-ревьюеры, затем разработчики расширений.
- Инкрементальные релизы, без переписывания.
- Каждая фича: Abuser Stories в `threat-model/` + Attack Test; `threat-gate` блокирует релиз (ADR-0008).
- Каждое крупное решение — ADR, начиная с 0018.

## Релизы

1. **Миграции** (ADR-0018). Нумерованные миграции с контрольными суммами; применяются админом из панели (TOTP-подтверждение, бэкап, аудит) или `bin/bastion migrate`. Обычные запросы схему не меняют.
2. **i18n.** Вариант entry на язык (`translation_group`), свой slug и статус; URL `/en/…`, `/ru/…`; набор языков настраивается. Админка — каталоги строк, EN/RU на пользователя.
3. **Ревизии и предпросмотр.** Неизменяемая ревизия на каждое сохранение, diff и откат, связь с audit ledger, хранятся бессрочно. Предпросмотр — подписанный короткоживущий токен, только staff, `noindex`.
4. **Структура.** Иерархия страниц, редактор меню, блоки Code, Table, Callout.
5. **Дизайн.** Рукописный CSS на custom-property токенах + htmx, без сборки и без inline. Светлая/тёмная темы. Редизайн админки и тема документации.
6. **Рендер модели угроз.** Команда в `bin/` экспортирует модель hybridtm в JSON при релизе (хэш — в SBOM). Расширение рендерит страницы активов/угроз/мер, DFD в серверном SVG, матрицу покрытия со ссылками на Attack Tests.
7. **Поиск.** SQLite FTS5 / MySQL FULLTEXT за интерфейсом `SearchIndex`, индекс на язык, обновление при публикации.
8. **Запуск сайта.** VPS, SQLite, CDN. ADR синхронизируются из репозитория в read-only записи. Без комментариев — ссылки на GitHub Issues.
