# ADR-0009: Аутентификация

- Статус: принято
- Дата: 2026-10-30

## Контекст

Админка — ценнейший актив.

## Решение

argon2id; обязательный 2FA для Admin/Editor (passkeys приоритетно, TOTP запасной); опционально для Author. Split-token для сброса пароля и remember-me. Политика паролей zxcvbn. Обязательный HTTPS + HSTS. Комментаторы без аккаунтов.

## Уточнение: сброс пароля (2026-10-30)

- Канал — email через SMTP (только TLS 465 или обязательный STARTTLS 587/2525, проверка сертификата,
  хост — только имя). Резервный путь без почты — `bin/bastion reset-link <user>` (Emergency Access).
- Split-токен: selector 128 бит + verifier 256 бит (в БД только SHA-256), TTL 30 минут, одноразовый,
  новый запрос гасит старые ссылки. Токен сразу переносится из URL в сессию.
- Ссылка строится только из `site.url` (фиксируется при установке), не из заголовка Host.
- Ответ на запрос одинаков для любых email; письмо отправляется после отправки ответа
  (`fastcgi_finish_request`), чтобы время ответа не выдавало существование аккаунта.
  Без FastCGI (например, `php -S`) отложенная отправка выполняется в том же запросе — остаётся небольшой timing-канал.
- Не более 3 писем на аккаунт в час.
- **Второй фактор сброс не затрагивает**: захват почты не даёт захватить аккаунт.
  Потерянный TOTP восстанавливается только через CLI.
- Смена пароля увеличивает `credentials_version`; все сессии со старой версией недействительны.
