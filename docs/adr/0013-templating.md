# ADR-0013: Темы: logic-less Template DSL

- Статус: принято, уточнено 2026-10-30 (см. «Уточнение»)
- Дата: 2026-10-30

## Контекст

Темы с произвольным PHP = исполнение кода.

## Решение

Ограниченный DSL (if/each/include + whitelist хелперов от расширений с правом render) поверх dzentota/template-engine; типизированные переменные через template-variable с контекстным экранированием; скомпилированный кэш подписан HMAC. Тема — Extension с правом только render.

## Последствия

Нужно доработать template-engine.

## Уточнение (первый срез)

DSL **не компилируется в PHP**. Парсер строит AST из простых данных, Renderer его интерпретирует.
Кэш хранит JSON-AST с HMAC-SHA256 (SignedAstCache).

Причина: компиляция в PHP + подписанный кэш оставляла бы класс атак «исполнение кода из кэша»
(подмена файла между проверкой подписи и include — TOCTOU, либо eval). При интерпретации AST
тема физически не может исполнить код; подпись защищает только целостность разметки.
Стоимость — интерпретация на каждый рендер; для logic-less шаблонов она пренебрежимо мала.

Экранирование выполняет dzentota/template-variable. URL-контекст библиотеки (rawurlencode всей строки)
для href не подходит — фильтр `url` реализован в DSL как allowlist схем (http/https/mailto, относительные пути).
