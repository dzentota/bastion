# Как сообщить об уязвимости

Пожалуйста, не открывайте публичный issue об уязвимости. Воспользуйтесь закрытым сообщением об уязвимости в репозитории на GitHub (Security → Report a vulnerability).

Расскажите, что вы нашли, как это воспроизвести и что с этим может сделать нарушитель. Если проблема в библиотеке, которую использует Bastion, назовите её.

Остальные проблемы, в том числе ошибки в этой документации, можно присылать обычными issue.
