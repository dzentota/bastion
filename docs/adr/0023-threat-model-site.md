# ADR-0023: Модель угроз на сайте документации

- Статус: принято
- Дата: 2026-10-31

## Контекст

Сайт документации должен показывать модель угроз Bastion так, чтобы она не расходилась с кодом (docs/roadmap.md, релиз 6). Модель — hybridtm (`threat-model.php`), меры — атрибуты `#[Mitigation]` в коде, тесты атак — в `tests/`.

## Решение

- **Экспорт при сборке.** `bin/threat-model-export` строит `build/threat-model.json`: компоненты, зоны доверия, потоки, Abuser Stories с покрытием, меры с местом в коде, тесты атак (по «Abuser story: …» в docblock), находки анализатора с решениями. Формат свой (`bastion-threat-model`, v1), детерминированный. Работает только при сборке (hybridtm — dev-зависимость); веб-процесс PHP-модель не исполняет. SHA-256 экспорта — в метаданных SBOM, `bin/sbom verify` его проверяет.
- **Потоки данных** добавлены в модель (11). Их находки анализатор теперь проверяет; ложные срабатывания «шифрования в пути» для локального файла и вызовов внутри процесса записаны как risk tracking `false-positive` с обоснованием, остальные открыты и видны на сайте.
- **Модуль ядра, а не расширение** (отклонение от вопроса 13 при обсуждении): API расширений умеет только helpers и чтение контента, страница-возможность была бы новой поверхностью атаки. Модуль `ThreatModel`: строгий разбор экспорта (недоверенный вход), представления, SVG-диаграмма на сервере.
- **Проза — в CMS.** Блок «Модель угроз» (overview, matrix, findings, dfd) вставляется в любую страницу; вокруг — обычный текст. Страницы историй — `/{язык}/threats/{id}`, сводная — `/{язык}/threats`. Нет экспорта или он не прошёл проверку — сообщение вместо данных, не ошибка.
- **Гейт строже.** `bin/threat-gate` падает и на истории без теста атаки (UNTESTED) — требование ADR-0008 теперь проверяется.

## Последствия

- Abuser Stories: threat-model-export-tamper, svg-injection.
- Тексты историй и находок — на английском (язык модели); интерфейс страниц переведён.
- Линии потоков к внешним службам на диаграмме могут пересекать узлы зоны хостинга; маршрутизации линий нет.
