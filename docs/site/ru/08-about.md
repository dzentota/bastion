# О проекте

Bastion — практическое доказательство AppSec Manifesto: настоящий продукт, решения о безопасности которого записаны, проверены тестами и опубликованы.

Архитектурные решения опубликованы ровно так, как они хранятся в репозитории, — в разделе «Архитектурные решения» (/ru/adr).
