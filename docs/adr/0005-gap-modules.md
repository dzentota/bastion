# ADR-0005: Недостающие компоненты — модули CMS, вынос по правилу трёх

- Статус: принято
- Дата: 2026-10-30

## Контекст

Нет готовых RBAC, медиа, CSP-заголовков, AppSensor-детектора, аудита, rate limiting.

## Решение

Реализуем внутри CMS; выносим в отдельную библиотеку dzentota после трёх применений и стабилизации API.

## Последствия

Меньше преждевременных абстракций.
