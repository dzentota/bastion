# Модель безопасности

Каждая функция Bastion начинается с Abuser Stories: кто атакует, чего хочет и зачем. История называет слабости, которыми пользуется атака, и сборка не проходит, пока в коде нет меры защиты для каждой из них и пока тест атаки не ссылается на историю.

Виды ниже не написаны вручную. Они собираются при выпуске релиза из модели угроз в репозитории, атрибутов мер защиты в коде и тестов атак. Откройте любую историю — там указано точное место в коде. Тексты историй — на английском, языке модели.
