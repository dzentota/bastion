# Установка

## Требования

| Компонент | Минимум | Примечание |
|---|---|---|
| PHP | 8.3 | расширения: pdo_sqlite или pdo_mysql, sodium, mbstring |
| База данных | SQLite 3.27+ с FTS5 или MySQL / MariaDB (InnoDB) | проще всего — SQLite |
| HTTPS | обязателен | по HTTP приложение не работает |

## Проверьте и загрузите релиз

У каждого релиза есть контрольная сумма SHA-256 и SBOM в формате CycloneDX. Проверьте архив до распаковки.

```bash
shasum -a 256 -c bastion-1.0.0.zip.sha256
unzip bastion-1.0.0.zip
```

Корень веб-сервера — каталог public. Всё остальное, включая var, должно быть вне document root.

> В каталоге var лежат база данных, ключи и якорь журнала аудита. Он никогда не должен быть доступен по HTTP.

## Запустите веб-установщик

Откройте в браузере /install. Чтобы доказать, что сайт ваш, вставьте токен из файла var/install.token. Установщик спросит языки сайта, создаст первого администратора и отключится.

Прежде чем первый вход завершится, администратор должен подключить второй фактор — приложение-аутентификатор.

## После установки

- Выполните на сервере bin/sbom verify: команда сверяет vendor/, шрифты и экспорт модели угроз с SBOM.
- Если можете, подключите для медиа S3-совместимое хранилище; до тех пор панель показывает предупреждение о сниженной защите.
