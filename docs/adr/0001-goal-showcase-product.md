# ADR-0001: Цель: витрина-доказательство в форме реального продукта

- Статус: принято
- Дата: 2026-10-30

## Контекст

Нужно доказать на практике AppSecManifesto и библиотеки dzentota, при этом продукт должен быть пригоден аудитории WordPress.

## Решение

Bastion — настоящий продукт. При конфликте безопасность > удобство; каждая цена удобства фиксируется отдельным ADR.

## Последствия

Некоторые привычные для WordPress возможности будут сознательно отсутствовать или ограничены.
