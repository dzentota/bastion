# ADR-0021: Дерево страниц, редактор меню, блоки Code/Table/Callout

- Статус: принято
- Дата: 2026-10-31

## Контекст

Сайту документации нужны разделы с вложенными страницами, управляемое меню, примеры кода, таблицы и врезки (docs/roadmap.md, релиз 4).

## Решение

- **Дерево страниц** (миграция 0005): `parent_id` и `position` у страниц. Родитель — страница того же языка; глубина не больше 4; цикл и превышение глубины отклоняются при сохранении, а все обходы дерева ограничены по глубине (цикл, внесённый в БД в обход приложения, не вешает рендер). URL не зависят от дерева — перенос страницы не ломает ссылки. Перевод получает родителем перевод родителя, если он есть.
- **Навигация в теме**: крошки, раздел (корень и опубликованные потомки) и список дочерних страниц. Черновики в навигации не видны; неопубликованный предок обрывает крошки.
- **Редактор меню** `/admin/menu`: по языкам, порядок, удаление, добавление страниц этого языка; право `content.publish`; запись `menu_updated` в журнале аудита. Дерево и меню, как рубрики, не версионируются.
- **Блоки.** Code — язык из закрытого списка (подпись и класс `language-*`, без подсветки на клиенте), текст выводится как есть; Table — простой текст, ряд на строку, ячейки через `|`, до 50 рядов, 8 колонок, 500 символов в ячейке, необязательная строка-заголовок; Callout — note, warning, danger. Двунаправленные управляющие символы (Trojan Source) запрещены во всём тексте блоков.

## Последствия

- Abuser Stories в `threat-model/structure.php`: page-tree-cycle, trojan-source, table-bomb, menu-tamper.
- Таблицы без объединения ячеек и выравнивания; код без подсветки синтаксиса — если она понадобится, только на сервере.
