# ADR-0017: Первый вертикальный срез

- Статус: принято
- Дата: 2026-10-30

## Контекст

Нужно проверить весь процесс сквозным сценарием.

## Решение

Установщик → вход админа (passkey + TOTP) → создание поста из блоков → публикация → публичный рендер через Template DSL. Вместе с моделью угроз, Detection Points и CI-гейтом.
