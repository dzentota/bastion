# ADR-0002: Платформа: PHP 8.3+, shared-хостинг, веб-установщик

- Статус: принято
- Дата: 2026-10-30

## Контекст

Целевая аудитория — нетехнические владельцы сайтов на shared-хостинге.

## Решение

PHP 8.3+, MySQL/MariaDB и SQLite. Установка: залить файлы + веб-установщик (самоотключается). Docker — опция. Никаких демонов.

## Последствия

Out-of-process изоляция, очереди и т.п. недоступны; решения должны работать в одном PHP-процессе.
